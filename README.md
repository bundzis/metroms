# metroms
Coupled ROMS-CICE through MCT

Please consult the README-file in the apps-directory for compiling options

For citing of this code, see: https://doi.org/10.5281/zenodo.597679

Example app Arctic-20km can be found here: https://github.com/nilsmkMET/arctic-20km


Bri edited to add scripts in metroms/tools/Perlmutter_tools to help with compiling ROMS-CICE on Perlmutter. However we are pivoting to an idealized ROMS-Budgell model instead so these scripts are here for reference but not actuavely used. Additionally, I did not add the DVD (discrete variance decay) algorithm into the code despite the branch name (:
